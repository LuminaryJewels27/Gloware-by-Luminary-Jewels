Photos for the backgrounds on the design page.

Name each file after the option's id — the exact filename for every one is
listed in photo-checklist.html, which you can just open in a browser.

.jpg, .jpeg, .png and .webp all work. Square, around 800x800.

Photos stay hidden on the shop until you open design.html and change
    const AUTO_IMAGES = false;
to
    const AUTO_IMAGES = true;
